# PicoScribe firmware

Part of [PicoScribe](../README.md). Raspberry Pi **Pico 2 W** firmware: receive ASCII text over Bluetooth Low Energy (Nordic UART Service) and type it into a host computer as a **USB HID keyboard**.

Stack: Pico SDK 2.3.1, TinyUSB, BTstack, Raspberry Pi Pico 2 W (dual-core).

Debug logs go over **UART** (USB is reserved for the keyboard).

## What it does

1. Core 0 runs the BLE Nordic UART Service (NUS) as **PicoScribe** and accepts writes on the NUS RX characteristic.
2. The characters written to this attribute are passed to Core 1 via the multi-core and interrupt-safe queue from `pico/util/queue.h`.
3. Core 1 receives characters from the queue and sends them to the USB host as HID keyboard keystrokes (US layout; non-ASCII bytes are skipped).

## Requirements

- Pico 2 W board (`PICO_BOARD=pico2_w`)
- [Raspberry Pi Pico SDK](https://github.com/raspberrypi/pico-sdk) 2.3.1 with CMake, Ninja (or Make), and the ARM GCC toolchain, with `PICO_SDK_PATH` set — **or** the [Pico VS Code extension](https://marketplace.visualstudio.com/items?itemName=raspberry-pi.raspberry-pi-pico), which provides the SDK and toolchain

## Build

### VS Code (recommended)

1. Open this `firmware/` directory in VS Code with the Pico extension installed.
2. Let the extension resolve the SDK / toolchain if prompted.
3. Build the `picoscribe` target with **Compile**.
4. Put the Pico in BOOTSEL mode, then flash with **Run**.

### Command line

```bash
# With PICO_SDK_PATH pointing at the SDK, or the Pico VS Code layout under ~/.pico-sdk:
cd build && cmake -G Ninja ..
ninja
```

`build/picoscribe.uf2` is generated by the build.

## Flash

1. Hold BOOTSEL, plug the Pico into USB, then release.
2. Copy the UF2 onto the mounted mass-storage volume, or use `picotool`:

```bash
# macOS (volume name may vary)
cp build/picoscribe.uf2 /Volumes/RP2350/

# Linux (mount path may vary)
cp build/picoscribe.uf2 /media/$USER/RP2350/

# Or with picotool
picotool load build/picoscribe.uf2 -fx
```

With the Pico VS Code extension, **Run** after BOOTSEL also flashes the board.

## Usage

1. Plug the Pico into a host computer; it enumerates as a USB HID keyboard.
2. Use [nRF Connect](https://www.nordicsemi.com/Products/Development-tools/nRF-Connect-for-mobile) (or the PicoScribe iPhone app) to connect to **PicoScribe** and write text to the NUS RX characteristic.
3. The text is typed into the focused window on the host.
